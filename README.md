# Technical Details 


This website is built with Quarto: an open-source publishing framework for reproducible and interactive documents.

Language and framework: Quarto with Markdown, R, and HTML.
Styling: Custom SCSS theme with coordinated light and dark variants.
Structure overview:
- `_quarto.yml` — global site configuration and navigation settings.
- `index.qmd` — homepage entry point.
- `/about/` — personal and professional background.
- `/blog/` — posts and research notes on methods, modeling, and open science.
- `/cv/` — academic curriculum and timeline.
- `/research/` — complementary materials and updates related to my published papers.
- `/assets/` — SCSS templates, color palettes, logos, and other design elements.

All posts and pages are rendered to static HTML using Quarto’s publishing engine and deployed automatically through GitHub Pages.
